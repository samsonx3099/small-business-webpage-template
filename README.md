# Oak & Ivy — Small Business Website Template

A polished, responsive, single-page HTML template for local service businesses. It is built with plain HTML, CSS, and JavaScript, so it is easy to customize, host, and resell.

## Preview

Open `index.html` directly in a browser, or use any local web server. No build tools or dependencies are required.

## Customize it

1. **Business identity:** Replace `Oak & Ivy` throughout `index.html` with the client's business name.
2. **Copy and contact details:** Update the headline, services, phone number, email, location, reviews, and opening hours.
3. **Images:** Replace the `.image-placeholder` element in `index.html` with an image, for example:
   ```html
   <img class="hero-image" src="images/project.jpg" alt="Description of the project">
   ```
   Add `object-fit: cover; width: 100%;` to `.hero-image` in `styles.css`.
4. **Colors and fonts:** Change the color variables at the top of `styles.css`. Google Fonts can also be swapped in the `<head>`.
5. **Contact form:** Replace `your-form-id` in the Formspree action URL with the client's form endpoint, or connect it to another form provider.
6. **Social links:** Replace the placeholder `#` URLs with real social profiles.

## Deploy

The template works on GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any standard web host. For GitHub Pages, enable Pages in the repository's **Settings → Pages** menu and select the `main` branch.
